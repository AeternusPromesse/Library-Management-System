# 图书馆管理系统演示脚本

> 用于本地运行、录制功能展示。按顺序操作即可完整展示注册、登录、借还书、图书管理、查询统计、推荐审阅等全部功能。

## 一、运行准备

1. 若项目根目录存在 `data` 文件夹，请先删除（数据文件与旧版本不兼容；删除后首次运行会自动初始化演示数据）。
2. 编译并运行（PowerShell 中执行）：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8   # 防止中文乱码
mvn -q compile
java "-Dfile.encoding=UTF-8" -cp "target/classes;$env:USERPROFILE\.m2\repository\com\google\code\gson\gson\2.11.0\gson-2.11.0.jar" com.library.Main
```

## 二、系统自带的初始数据（演示数据）

- 用户（`UserManager.initUsers()`）：1 个管理员 `admin/admin123`、1 个操作员 `operator/operator123`、1 个教师 `teacher/teacher123`、2 个学生 `student1/student123`、`student2/student123`
- 图书（`BookManager.init10Books()`）：10 本书，每本 5 个副本，覆盖哲学、宗教、社会科学、自然科学、文学、历史、艺术 7 种类型
- 借阅记录（`LoanManager` 演示初始化）：5 条记录，包含
  - 借阅中 2 条、超期未还 1 条（借阅ID:1，超期 10 天）
  - 已归还 2 条，其中 1 条逾期 5 天、罚款 2.5 元（借阅ID:4）

## 三、演示步骤

### 1. 注册（演示输入验证与重复校验）

1. 主菜单选 `1`（注册），用户名输入 `zhangsan`
2. 手机号先输入 `123` → 提示"手机号格式不正确"并要求重新输入（展示 InputData 手机号验证），再输入 `13812345678`
3. 选择专业（如 `2` 软件工程）、选择角色 `2`（student）→ 按提示输入年级、所属学院 → **注册成功**
4. 再次注册，用户名输入 `student1` → **提示"注册失败：用户名已存在"**（展示同名账号不能重复注册）

### 2. 学生：借书、个人借阅查询、还书

1. 主菜单选 `2`（登录），输入 `student1 / student123`，角色选 `2`（student）
2. 菜单选 `1`（借书）：屏幕显示"我的未还借阅"（含 1 条超期未还）和可借图书列表；输入图书ID `5` → 借阅成功（分配副本ID），记录立刻显示在个人借阅中；输入 `0` 退出借书
3. 菜单选 `3`（个人借阅查询）：依次演示 `1` 全部借阅、`2` 未还借阅、`3` 日期范围查询（如 2026-10-01 ~ 2026-12-31），`0` 返回
4. 菜单选 `2`（还书）：输入刚才借到的副本ID → 归还成功；未还记录中消失；输入 `0` 退出还书
5. `0` 退出登录

### 3. 教师：推荐图书

1. 登录 `teacher / teacher123`，角色选 `3`（teacher）
2. 菜单选 `4`（推荐图书），输入书名 `三体`、作者 `刘慈欣` → 推荐成功（状态：待审阅）
3. `0` 退出登录

### 4. 操作员：图书管理（Operator 菜单）

1. 登录 `operator / operator123`，角色选 `4`（operator）
2. 选 `1`（添加书籍）：先显示所有图书列表；输入新书信息（如：万物简史 / 比尔·布莱森 / 类型4 / 商务印书馆 / 30 / 49.5 / 库存3）→ 添加成功，**新书显示在图书列表第一行**，且自动生成 3 个副本；输入空行退出添加
3. 选 `2`（查看所有书籍）：输入关键字 `简史` 模糊查询；直接回车显示全部
4. 选 `3`（废弃图书）：先输入图书ID `1` → **提示"还有副本外借，不能废弃"**（演示校验）；再输入图书ID `9` → 废弃成功
5. 选 `5`（图书副本编辑）：输入图书ID `6` → 显示副本列表；选 `1` 新增副本 → **库存 5 变 6**；选 `2` 修改副本状态（副本ID `26` → 状态选 `2` 损坏）→ **库存自动变回 5**（库存与正常副本数一致）
6. 选 `4`（编辑图书）：输入图书ID `2`，更新书名/作者/类型/出版社/期限/价格 → 修改成功（库存、副本、状态不变）
7. `0` 退出登录

### 5. 管理员：查询、统计、审阅（Admin 菜单）

1. 登录 `admin / admin123`，角色选 `1`（admin）
2. 选 `1`（用户信息查询）：输入关键字 `student` 模糊查询；直接回车显示全部用户（含刚注册的 zhangsan）
3. 选 `2`（借阅记录查询）：
   - 子菜单 `1` 关键字查询：输入 `student1`
   - 子菜单 `2` 超期借阅查询：直接回车 → 显示超期未还记录
   - 子菜单 `3` 日期范围查询：输入 2026-01-01 ~ 2026-12-31
   - `0` 返回
4. 选 `3`（借阅数据统计）：显示按图书类型统计（7 种类型全部显示）和按用户专业统计
5. 选 `6`（审阅推荐图书）：显示教师推荐的《三体》，输入推荐ID `1`，选择"通过" → 审阅完成
6. `0` 退出登录

### 6. 日志展示（可选）

登录与所有非查询操作均已写入日志，可打开 `data/logs.json` 查看，日志包含时间与操作人信息，例如：

```
2026-11-15 10:00:00 [student1] 登录系统
2026-11-15 10:02:11 [student1] 借阅《金刚经》(副本#21)
2026-11-15 10:05:30 [operator] 添加图书《万物简史》
```

## 四、退出

主菜单选 `3` 退出系统，数据自动保存在 `data/*.json`。
